\# W10 Interactive Data App



\## 專案介紹

這是一個使用 Python、Pandas 和 Streamlit

製作的互動式學生資料分析應用程式。



\## 功能

\- 搜尋學生姓名

\- 依班級篩選資料

\- 選擇分析科目

\- 設定分數門檻

\- 計算符合條件的人數與平均分數

\- 顯示學生資料

\- 無符合條件資料時顯示提醒



\## 使用技術

\- Python

\- Pandas

\- Streamlit



\## 安裝套件

pip install streamlit pandas



\## 執行方式

streamlit run main.py



\## 資料說明

本專案使用 12 筆模擬學生資料，

僅供程式練習與展示。
